# lynx-android-plugins API documentation

This artifact contains Android connector APIs for Lynx.

The public usage and integration documentation is maintained in the repository
README: https://github.com/carlos-sweb/lynx-android-plugins#readme

Each artifact also publishes a sources JAR. This Javadoc placeholder exists so
that every Android artifact has the documentation JAR required by Maven
Central, including artifacts whose public API is implemented in Kotlin.
